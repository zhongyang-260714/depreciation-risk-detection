## 二、下载途径（推荐巨潮资讯网）

### 2.1 巨潮资讯网下载步骤

**网址**：http://www.cninfo.com.cn

**步骤**：
1. 打开巨潮资讯网首页
2. 在顶部搜索框输入股票代码（如 `603019`）或公司简称（如 `中科曙光`）
3. 进入公司信息页面
4. 点击左侧菜单「定期报告」或「年报」
5. 找到「2024年年度报告」（发布时间：2025年3-5月）
6. 点击「下载PDF」按钮，保存到本地

**注意事项**：
- 巨潮资讯网是**中国证监会指定信息披露平台**，所有A股公司年报均在此首发
- 年报PDF通常较大（200-500页，5-20MB），下载需要稳定网络
- 若巨潮下载缓慢，可备选：上交所官网（http://www.sse.com.cn）或深交所官网（http://www.szse.cn）

## 三、P7系统操作步骤

### 3.1 启动Streamlit系统

```bash
# 在项目根目录执行
streamlit run src/dashboard/app.py
```

系统启动后，在浏览器中访问 `http://localhost:8501`

### 3.2 进入P7智能标注页面

1. 左侧导航栏选择 **P7 · 智能标注**
2. 在输入模式中选择 **「A股年报（上传PDF）」**

### 3.3 上传PDF并运行

1. 点击「上传 A股年报 PDF 文件」，选择已下载的PDF
2. 在「股票代码」输入框填写对应代码（如 `603019.SH`）
3. 确认「报告年份」为 2024
4. 点击 **「▶ 启动智能标注流水线」**
5. 等待约30-60秒（首次运行）或10-30秒（缓存命中）

### 3.4 对照人工标注

AI标注完成后，系统会自动查找 `data/annotated_cn/` 目录下对应公司的人工标注JSON，并排显示：
- 左侧：🤖 AI草拟评分
- 右侧：👤 人工标注评分

**重点关注**：
- 综合分差值 > 0.5：需复核维度分
- 综合分差值 > 0.8：需重点复核
- D1维度分差值 > 1：检查资产类型识别是否正确

## 四、各公司标注重点提示

### 4.1 中科曙光（603019.SH）

**人工标注要点回顾**：
- 生产设备折旧年限5-10年（技术周期2-3年，上限偏长）
- 无形资产减值1.37亿（大数据智能引擎6.0系统减值2072万）
- 无固定资产折旧年限变更

**AI验证重点**：
- D1：是否将生产设备正确识别为server类型（基准1.5年）
- D3：是否识别到无形资产减值信号
- D4：研发费用12.92亿（占营收9.83%）是否被正确提取

### 4.2 数据港（603881.SH）

**人工标注要点回顾**：
- IDC数据中心运营商，核心资产为机房设备、服务器、网络设备
- 折旧政策对IDC运营商至关重要

**AI验证重点**：
- D1：数据中心设备折旧年限是否合理（技术迭代1.5-3年）
- D4：CAPEX强度（IDC行业通常较高，需关注）

### 4.3 寒武纪（688256.SH）

**人工标注要点回顾**：
- AI芯片设计公司，研发投入极高
- 固定资产以研发设备、测试设备为主

**AI验证重点**：
- D1：研发设备折旧年限vs技术迭代速度（AI芯片1-2年迭代）
- D4：研发支出资本化率（芯片设计公司通常较高）
- D5：AI芯片行业竞争（vs英伟达、华为昇腾）

### 4.4 浪潮信息（000977.SZ）

**人工标注要点回顾**：
- 服务器ODM/自主品牌厂商
- 固定资产以生产线设备、测试设备为主

**AI验证重点**：
- D1：生产线设备折旧年限（服务器制造设备5-10年，技术周期2-3年）
- D5：国产服务器替代趋势（vs华为、新华三）

### 4.5 科大讯飞（002230.SZ）

**人工标注要点回顾**：
- AI语音技术公司，软件/平台资产为主
- 需注意无形资产摊销与固定资产折旧的区分

**AI验证重点**：
- D1：**注意区分**无形资产摊销（不计入D1）和固定资产折旧
- D3：商誉减值风险（科大讯飞历史上有多笔并购）
- D4：研发投入强度（AI公司通常>15%）

### 4.6 奥飞数据（300738.SZ）

**人工标注要点回顾**：
- IDC/云计算服务商
- 与数据港同属IDC行业，可横向对比

**AI验证重点**：
- D1：与数据港对比，IDC设备折旧政策是否一致
- D4：CAPEX扩张速度（IDC行业近年快速扩张）

## 五、常见问题

### Q1：巨潮资讯网下载失败怎么办？

**A**：巨潮API对自动化请求有反爬限制，系统P7的「自动下载PDF」模式可能失败。建议：
1. 直接访问巨潮资讯网网页版手动下载
2. 备选：上交所/深交所官网下载
3. 下载后通过P7「上传PDF」模式导入

### Q2：AI评分与人工评分偏差大怎么办？

**A**：偏差可能来自以下原因，逐一排查：
1. **PDF文本提取不完整**：pdfplumber对某些PDF格式支持不佳，可能导致文本缺失
2. **关键词定位遗漏**：中文关键词矩阵可能未覆盖某些特定表述
3. **资产类型误判**：AI可能将"数据中心设备"误判为"通用设备"
4. **规则引擎阈值边界**：如MU的D1阈值问题（2.0x刚好卡在阈值下方）

排查方法：
- 查看P7页面的「🔍 D1 年限提取调试信息」展开项
- 检查「验真未通过的信号」列表
- 对照PDF原文确认关键数字

### Q3：如何更新人工标注？

**A**：AI标注完成后，若确认AI结果更准确：
1. 点击「✅ 确认入库（confirmed）」保存AI标注
2. 系统会保存到 `data/annotated/` 目录
3. 如需覆盖原人工标注，需手动将新标注文件复制到 `data/annotated_cn/` 并修改文件名
