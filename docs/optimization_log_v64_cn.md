## 二、本轮优化内容（v6.4-CN / P7 v3.2）

### 2.1 新增：A股财年定义与下载指南专节

**位置**：P7页面「必要说明」可折叠区域内（`p7_ai_annotation.py` line 244-287）

**设计思路**：
用户提出的核心问题是"到底需要下载哪三年的财报"。中国A股与美国在财年定义上存在本质差异，如果不明确说明，团队成员在下载时容易混淆。

| 对比维度 | 美国 | 中国A股 |
|---------|------|---------|
| 财年定义 | 各公司自定义（如NVIDIA是2月-次年1月） | **统一=自然年**（1月1日-12月31日） |
| 命名方式 | FY2025（财年） | 2024年年度报告（报告期） |
| 发布时间 | 财年结束后2-3个月 | 次年3-5月 |
| 当前可下载范围 | FY2022-FY2024（10家公司×3年=30份） | 2022-2024年报（6家公司×3年=18份） |
| **不可下载** | FY2025尚未发布 | **2025年报尚未发布**（需等2027年3-5月） |

**关键结论**：
- ✅ 应下载：**2022年、2023年、2024年** 年度报告
- ❌ 不应下载：2025年年度报告（尚未发布）
- 六家公司一视同仁，均适用自然年制，无需区别对待

### 2.2 页面美观度优化

**优化1：双栏信息卡片（info + warning）**

```python
col1, col2 = st.columns(2)
with col1:
    st.info("中国 A 股财年 = 自然年...")
with col2:
    st.warning("⚠️ 不要下载 2025 年年报！...")
```

- 左侧 `st.info`（蓝色）：清晰阐述A股财年=自然年的核心事实
- 右侧 `st.warning`（黄色）：醒目提醒不要下载尚未发布的2025年报
- 视觉对比强烈，用户一眼就能抓住重点

**优化2：六家公司下载清单表格**

```python
download_df = pd.DataFrame([

    ...

st.dataframe(download_df, hide_index=True, use_container_width=True)
```

- 使用 `st.dataframe` 展示，支持排序和搜索
- 每家公司一行，三财年状态一目了然
- FY2024标注"已有标注"，提示用户优先级
