## 3. 四大亮点（这是你们的"真东西"，答辩要放大）

1. **"证据链标注"范式原创且可信**：四列结构（原文—行号—会计含义—推断链）+ XBRL 噪声排除 + "直接信号缺失即声明未发现"的纪律，直接回应了财报文本研究"结论不可验证"的痛点。这是评委最买账的差异化点。
2. **"双向验证"叙事极具张力**：证伪"Oracle 5→8 年"（真身是 Intel）、证实"Oracle 5→6 年"，把方法论变成故事，答辩记忆点强。
3. **面板扩样带来的真发现**：8 个变更年评分跳升、Oracle/Meta"连续延长者"、折旧指纹、四通道分化——这些都是 v1.0 没有的、靠扩样才浮现的硬证据。
4. **落地方案精准对准发榜方**：5.4.2 把 5D-DRS 直接写成科技保险核保/定价因子，且引用四部门《科技保险意见》，"以题为用"做得漂亮。

## 5. 未来方向与改进方案（优先级排序）

### 方向 A（最高优先级，1–2 周可完成，直接涨分）
1. **做实"可验证系统"**：把 `POST /predict` 接到 `training_v06` CSV + 30 JSON，实算 5D-DRS；把占位 API 变成真接口。→ 第 4 维从"演示外壳"变"真东西"。
2. **补中国迷你验证集（2 家）**：选 1 家智算中心运营商 + 1 家 AI 芯片企业，做完整证据链标注 + 五维评分，作为第六章实证支撑。→ 第 1/2 维跃升。
3. **消项 P0 硬伤**：附录 E、学术文献、META 评分一致性、API 声明对齐。

### 方向 B（中期，提升学术深度与原创性）
4. **轻量"技术半衰期"量化**：用二手 GPU 价格/MLPerf/代际间隔构建可解释曲线，替代"行业共识估计"，作为 D1 错配比的外部锚。
5. **信号自动分类器**：用 30 份标注训练一个文本分类模型（BERT/FinBERT 小规模），自动识别风险信号与严重度，把单份标注从"数天"压到"分钟"，回应赛题"AI 技术支撑与实际提升"。
6. **规则引擎双准则**：把 5D-DRS 与 R1–R4 同时编码 GAAP 与 CAS 6，兑现 README 承诺的"通用算法框架"，强化"可落地性"。

### 方向 C（长期，形成资产与壁垒）
7. **风险数据资产化**：把标注库做成可公开/可授权的"科创折旧风险信号数据库"，呼应赛题"风险数据资产化的实现机制"，争取附加分。
8. **RegTech 原型**：R4 规则部署为定期报告自动初筛，对接监管沙盒叙事。
9. **滚动监测"连续延长者"**：持续跟踪 Oracle/Meta 第三次延长与表外租赁兑现，形成动态证据链。
